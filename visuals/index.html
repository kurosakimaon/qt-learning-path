VISUALS · 图解专区

十六张会动的图，把 Qt 里最绕的那几层讲透

每一页都是同一套骨架：左边一张 SVG，右边一段讲解加一段代码，底下是步骤条。按 ▶ 自动播放 会一步步推进，也可以点步骤条跳到某一步；键盘 ← → 翻步，Home / End 到头尾。图是画给你看「东西在哪儿、按什么顺序动」的，代码是给你对回讲义的具体文件的——两样一起看，才不容易记混。

START · 起步讲义 start/
🚀

从 main() 到窗口出现

一行 w.show() 背后到底发生了七件事：进程启动、QApplication 与平台插件、构造控件时还没有原生窗口、exec() 接管、布局与绘制、退出与析构顺序。

第壹阶段 · 起步
METAOBJECT · 元对象系统讲义 metaobject/
⚙️

信号槽与 moc 到底生成了什么

emit clicked() 展开成什么、moc 吐出的 qt_static_metacall 长什么样、连接是怎么在 connect 时就把指针换成分发表下标的，以及四种常见报错各对应哪一步断了。

第肆阶段 · 元对象
🔀

五种连接类型与跨线程排队

同一个 connect，槽可能在哪个线程跑？Auto 是在发信号那一刻按接收者线程判的；排队连接会把参数拷贝成事件塞进队列；BlockingQueued 在同线程直接死锁。

第肆阶段 · 元对象
🌳

QObject 对象树与所有权

setParent 只是记账，真正的清理发生在父对象析构时；children() 只给直接子对象，findChild 默认递归；deleteLater 靠一个 DeferredDelete 事件完成。

第肆阶段 · 元对象
EVENTS · 事件系统讲义 events/
🔄

事件循环到底在转什么

app.exec() 不是让程序停住，是开始分拣。同步的 sendEvent 与异步的 postEvent 谁拥有事件、一轮循环不等于一个事件、processEvents 怎么用、嵌套循环从哪来、怎么优雅退出。

第叁阶段 · 事件
🧩

事件过滤器：装在事件路上的关卡

三个安装位置（qApp / 目标对象 / 自己）、应用级到对象级到 event() 再到具体处理器的顺序、return true 为什么能把事件彻底掐掉，以及什么时候该用过滤器、什么时候宁可直接改写。

第叁阶段 · 事件
WIDGETS · 控件与布局讲义 widgets/
📐

布局协商：谁决定控件多大

控件的大小不是「设」出来的，是「谈」出来的。四路输入（sizeHint / minimumSizeHint / QSizePolicy / stretch）怎么汇成一次 setGeometry，以及为什么构造函数里读 width() 拿到的是草稿。

第贰阶段 · 控件
PAINTING · 绘图讲义 painting/
🎨

绘制管线：从 paintEvent 到屏幕

paintEvent 不是往屏幕上画，是往一张缓冲图上画。为什么双击缓冲是白送的、update() 为什么要合并、脏区是怎么省下来的、devicePixelRatio 不管会出现什么糊图。

第伍阶段 · 绘图
🧭

坐标系与变换：画到哪儿去了

「画错位置」和「点不准」其实是同一个问题。mapTo / mapFrom 的方向怎么记、pos() 与 geometry() 差在哪、变换的叠加顺序为什么不能反、命中测试怎么反着算回去。

第伍阶段 · 绘图
MODEL/VIEW · 模型视图讲义 model_view/
🗂️

模型/视图：数据流的四个角色

一屏格子背后是一个 QTableView 和零个「格子控件」（结构子控件实测 8 个，与行列数无关）。QModelIndex 是坐标不是身份、每个角色各问一次 data()、只问可见的那几十格、一次写回要经过哪几站。

第陆阶段 · 模型视图
✏️

委托的生命周期：画一格与管一个编辑器

paint 会被调成千上万次，编辑器却只在真正编辑时才造。四个编辑器函数的调用时机与数据流向、updateEditorGeometry 忘了写编辑器会跑到 (0,0)、提交时 commitData 与 closeEditor 的顺序。

第陆阶段 · 模型视图
THREADS · 并发与线程讲义 threads/
🧵

线程归属：QThread 到底让哪段代码跑在新线程

只有 run() 跑在新线程里，别的都在原线程。继承 run() 与 moveToThread 两条路的差别、跨线程信号为什么是唯一正路、共享数据的三档做法、以及怎么在不调 terminate() 的前提下收摊。

第柒阶段 · 线程
STORAGE · 数据与持久化讲义 storage/
📦

资源系统：把文件编进 exe

:/icons/save.png 这个路径在磁盘上并不存在。rcc 把文件变成一段 unsigned char[] 链进可执行文件，运行时读法和读普通文件一模一样；还有静态库里的 Q_INIT_RESOURCE、@2x 命名和缺插件这三类坑。

第捌阶段 · 存储
NETWORK · 网络讲义 network/
🌐

异步网络：一个请求的一生

get() 立刻返回，真正的工作在没有你的地方发生。三个对象的三个生命周期、正文只有 finished 之后才存在、两场考试（传输错误与状态码）、静默超时、进度里的 -1 总量，以及为什么取消要 abort() 而不是删对象。

第玖阶段 · 网络
QUALITY · 工程质量讲义 quality/
✅

四道质量门：让 bug 在最便宜的地方被抓住

静态门拦「写错」、单元门拦「算错」、界面门拦「接错」、交付门拦「带错」。每一道门用什么工具、失败时拿什么当证据、为什么顺序不能倒，以及 --self-check 与 ctest 的退出码为什么比日志更可信。

第拾阶段 · 工程质量
BUILD/DEPLOY · 构建与部署讲义 build_deploy/
🚚

部署：从 build 目录到别人电脑

「我这儿能跑」到「他那儿能跑」，中间隔着一个 deploy。windeployqt 读的是什么、带走的目录长什么样、0xC0000135 与「no Qt platform plugin」各缺哪块、qt.conf 与静态链接的代价。

第拾壹阶段 · 构建部署
用法：每页右上角的步骤条可以直接跳；▶ 自动播放 用每步预设的停留时间推进，看完自动停在最后一步。
