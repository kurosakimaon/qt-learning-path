NETWORK · 异步请求

get() 立刻返回，真正的工作在没有你的地方发生

Qt 的网络 API 天生异步：get() 返回一个 QNetworkReply 指针，然后立刻返回。响应体要等 finished 才有，错误要单独看，对象还得你自己删。把这条生命周期走完整，才能写出「不卡界面、不泄漏、不漏错误」的网络代码。
