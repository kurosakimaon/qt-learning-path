📖 模块简介

欢迎来到 Qt 的世界！本模块是全课程的第壹阶段「起步」，从第一个窗口讲起： 先立起 QApplication、把窗口 show() 出来、弄懂事件循环；再解剖一个 Qt 工程， 把 Q_OBJECT 与 moc 这第一道坎迈过去；接着把应用对象的职责、 信号槽交互、日志输出一讲讲铺开，最后落在无头运行与自动化自测—— 这一讲本身就是给后面所有示例「跑起来验一验」用的。

环境事实：本资料库基于 Qt 6.12.0，Windows 平台，MinGW-w64（MSYS2 ucrt64，gcc 15.2/16.2）， 构建用 CMake ≥ 3.21 + Ninja，语言标准 C++17（这是 Qt6 的最低要求）。 每一章都是完整可编译的示例 + 详细注释，且都设计成无人值守能自动跑完。

诚实标注：本机当前无法编译链接 Qt 程序（运行时库正在升级），本模块示例 未在本机实测编译；文中每一个类、函数、重载都对着本机 C:\msys64\ucrt64\include\qt6 里的真实头文件核对过。

📚 学习建议

  • 按顺序学：这 6 章是一条连贯主线，前面每一步都给下一步铺路。看不懂先记着往下走，很多概念到第 4、6 章会突然串起来。
  • 先读指南再动手：每一章动手前，先在本页点 📖 学习指南 和对应 .cpp 顶部的注释块，弄清「这一讲要解决什么」再敲。
  • 亲手把每个示例跑起来：Qt 是「跑起来才看得懂」的东西。每个示例都配了自动演示脚本，无人值守也能跑完、自己吐结论。
  • moc 坎别绕着走：第 2 步的 Q_OBJECT / moc / AUTOMOC 是 Qt 区别于普通 C++ 的地方，务必用三个小练习把「三种忘了」的报错都亲手撞一遍。
  • 理解事件驱动：第 1 步 show() + 第 4 步信号槽合起来，就是 Qt 的心智模型——「登记响应、交给事件循环」，不是「轮询查询」。
  • 记住「未在本机实测编译」：本机运行时正在升级，示例暂无可执行产物；但每个 API 都对着真实头文件核对过，你换到能编译的环境按注释里的 CMake 目标名构建即可。

👴 老师傅的话

徒弟，欢迎踏入 Qt 的大门。Qt 不是「多学几个类」那么简单，它是一整套把 C++ 和 GUI、事件、对象模型缝在一起的工程范式。入门别贪快，先把它「怎么活起来」这条主线摸清楚。

师傅给你几条起步忠告：

  • 第一条：QApplication 是一切的前提。 在它之前碰任何 QWidget 都是崩。窗口 show 了没东西、一闪而过，病根多半在你没让事件循环转起来。想看到真东西，就得把动作交给 exec() 之后。
  • 第二条：moc 这道坎要正面跨。 别怕 Q_OBJECT / AUTOMOC / .moc 这些词，它本质就是「一个帮你生成信号槽实现的代码生成器」。撞过三种报错，你就再不怕它。
  • 第三条：用无头自测当你的安全带。 第 6 步不是收尾的彩蛋，是全课后面每个 GUI 示例能自动化验证的地基。学会 grab() + 断言 + 退出码，你写的界面就再也不是「只能靠肉眼点」的死角。
  • 第四条：诚实对待环境。 本机此刻编不动，就大方标注「未实测编译」，但 API 一律查真头文件核对，绝不凭记忆。写 Qt 和做人一样：不确定就别乱说。

慢慢来，不急。起步阶段就是要稳。等你把这 6 章啃下来，事件循环、moc、信号槽、日志、无头自测都通了，就正式具备往「控件与布局」阶段进阶的本钱了。加油，徒弟！
